The page showed the shortcode because the CAD package was not loaded

Install both zips. The plugin zip registers [rgz_3d_cad_studio] even if the package failed. The package zip is the studio itself.

1. Plugin (required to fix the blank shortcode)

WP Admin → Plugins → Add New → Upload Plugin → this zip → Replace current with uploaded.

⬇ rgz-engineering-studio.zip

2. App package (the 3D studio)

WP Admin → RGZ Engineering Studio → Mechanical Deck → Apps → Install app package → tick Overwrite.

⬇ rgz-3d-cad-studio.zip
  1. Upload the plugin zip first and replace the existing plugin.
  2. Upload the app package zip with Overwrite.
  3. Open /rgz-3d-studio/ and hard-refresh (Ctrl+F5). Purge LiteSpeed cache if needed.

After step 1 alone the page will at least stop showing the raw shortcode (it will either run the studio or show an install hint).
